# ⚽ Soccer Team Manager: FUT Live Transfer & Match Simulator (3-Player Multiplayer)

An ultra-modern, zero-config **Soccer Team Manager & 3-Player Multiplayer FUT Draft Engine** built with Next.js 14, React, Tailwind CSS, WebRTC PeerJS, and Web Audio API.

Ready for 1-Click Deployment on **Vercel** with 0 Database Setup!

## ✨ Key Features
- **500+ World Footballers & Legends Database:** Verified 1:1 player photos, stats (PAC, SHO, PAS, DRI, DEF, PHY), clubs, nations, and price tags.
- **Session Randomization (80 Player Pool):** Every match draws 80 random unique players so every session is fresh.
- **"Siapa Cepat Dia Dapat" Live Transfer Market:** Real-time fast-claim market with $100M budget wallet, reselling, and position filters.
- **2D Tactical Football Pitch:** Interactive lineup visual for 4-3-3, 4-4-2, 3-5-2, and 4-2-3-1 formations.
- **Live 2D Match Simulator (Top Eleven Style):** 3-Way Round Robin League (P1 vs P2, P2 vs P3, P3 vs P1) with live radar dots, dynamic commentary, live tactics, and live reaction emotes.
- **Zero-Config P2P Multiplayer (PeerJS WebRTC):** 6-digit Room Code connection without needing Firebase or any backend database.
- **Web Audio API Synth Engine:** Native sound effects for whistle, crowd roar, coins, and clicks.

## 🚀 Local Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to play!

## ⚡ Deployment on Vercel

1. Push this repository to GitHub.
2. Import repository into [Vercel](https://vercel.com).
3. Click **Deploy**!
